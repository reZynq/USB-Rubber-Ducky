# DuckyScript for stealing WiFi Password and Information and Sending via EMAIl

Hello, this duckyscript can be used on a rasberry pi pico or encoded to be used on a hak5 rubber ducky. It performs a payload which takes targets wifi password and name and send it to you in a zip file via email

Instructions

1) Download the .txt file
2) If using Rubber Ducky, encode it and put it in
3) If using Rasberry Pi Pico, just rename it as payload.dd and put it into the storage
